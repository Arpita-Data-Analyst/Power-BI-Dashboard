# Power BI Sales Dashboard

## Project Overview
This project demonstrates the use of Microsoft Power BI to analyze and visualize sales data through an interactive dashboard.

## Tools & Technologies
- Microsoft Power BI Desktop
- Data Visualization
- Data Analysis
- Power Query

## Project Objectives
- Analyze sales performance.
- Present key business insights using interactive visualizations.
- Create an easy-to-understand dashboard for data-driven decision-making.

## Key Features
- Interactive dashboard
- Visual representation of sales data
- Business performance analysis
- Data-driven insights

## Project File
The Power BI dashboard is available in this repository:

`Sales Dashboard.pbix`

## How to View the Project
1. Download the `.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and its interactive visuals.
